## 🚀 Features

### 🏠 Home Section
- Full-width Bootstrap carousel slider  
- Promotional banners with CTA buttons  
- Smooth transitions and overlay effects  

### 🎯 Offers Section
- Interactive hover shine animation  
- Multiple discount cards (30%, 50%, 70%)  
- Overlay + call-to-action buttons  

### 🛒 Products Section
- Featured product grid layout  
- Hover image swap effect  
- Product badges (Sale)  
- Star rating system  
- Price with discount (`<del>` support)  
- Add to Cart button (UI ready)  

### 🔥 Special Sale Section
- Highlight product with description  
- Dynamic countdown timer (JavaScript)  
- Discounted pricing display  
- Fully responsive layout  

### 💬 Testimonials Section
- Carousel-based testimonials  
- User image, name & company  
- Smooth slider controls  

### 📩 Contact Section
- Contact form (Name, Email, Message)  
- Styled contact info cards with hover effects  
- Clickable:
  - 📍 Location (Google Maps)  
  - 📞 Phone  
  - 📧 Email  

### 📌 Footer Section
- Multi-column layout (Brand, Links, Support, Contact)  
- Social media icons  
- Hover animations  
- Developer credit section
